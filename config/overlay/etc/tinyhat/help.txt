Tiny Hat 1.0.3

Alt+Space	Application Menu
Alt+Shift+W	Close window (Alt+F4 also works)
Alt+Shift+F	Toggle fullscreen (Alt+Enter also works in some applications).
Alt+Tab	Jump between windows
Ctrl+Alt+Up / Down	Audio volume
Alt+F2	Run a command (Win+R also works)

Ctrl+Alt+R	Terminal
Ctrl+Alt+N	NetSurf web browser
Ctrl+Alt+K	Keyboard layout selection
Ctrl+Alt+B	Bluetooth devices
Ctrl+Alt+W	Wi-Fi settings
Ctrl+Alt+C	Example game in C (2x Ctrl+Space to run)
Ctrl+Alt+F	Example game in Fennel and LÖVE (2x Ctrl+Space to run)
Ctrl+Alt+G	Example GBA program in C (2x Ctrl+Space to run)
Ctrl+Alt+J	Example SNES program in C (2x Ctrl+Space to run)
Ctrl+Alt+O	Example DOS program in C (2x Ctrl+Space to run)
Ctrl+Alt+P	Example point-and-click game in Lua (2x Ctrl+Space to run)
Ctrl+Alt+U	Example C64 program in C (2x Ctrl+Space to run)
Ctrl+Alt+X	Example 256 byte demoscene intro (2x Ctrl+Space to run)
Ctrl+Alt+L	Lock the screen (the default password is "tinyhat")
Ctrl+Alt+H	Toggle sharing
Ctrl+Alt+M	Download and run a homebrew game (NES, SNES, GBA, Genesis or Master System)
Ctrl+Alt+A	Scan drives for ScummVM games
Ctrl+Alt+S	ScummVM
Ctrl+Alt+D	DOSBox-X
Ctrl+Alt+T	TIC-80 fantasy console
Ctrl+Alt+Z	ZSNES 2
Ctrl+Alt+V	C64 (VICE)
Ctrl+Alt+I	LibreSprite

Right click desktop	Toggle background
Alt+Left drag	Move a window
Alt+Right drag	Resize a window
Alt+1..4	Go to desktop 1-4 (combine with Shift to send a window there)

Ctrl+Alt+Shift+Q	Power off

USB sticks and CDs show up in /media and as D: in DOSBox-X. DOS games can be placed in ~/DOS,
which is C: in DOSBox-X. A hard disk in this PC with DOS on it becomes C: and ~/DOS becomes E:.
